# HR Analytics Dashboard

It’s an HR Analytics Dashboard built using Power BI, focused on analyzing employee attrition.

The dashboard is designed using Power BI and includes KPIs, charts, and insights to support data-driven HR decision-making.

The dashboard helps us understand:

- How many employees are leaving

- Which job roles are most affected

- How factors like age, gender, education, and salary impact attrition

 ## Key Insights:
 
Most attrition occurs in the 26–35 age group.

Laboratory Technicians and Sales Executives have the highest attrition.

Employees with lower salary slabs show higher turnover.

Life Sciences graduates form the majority workforce.
